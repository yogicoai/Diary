# 그림칸 배경 프롬프트 (복사해서 바로 쓰는 판)

장면마다 회색 칸 하나를 통째로 복사해서 붙여 넣으면 돼요.

- 비율 **4:3**, 크게(2K 정도)로 뽑기
- 참고 그림 `Desktop/book/drafts/bg/_ref-original.png` 를 같이 첨부 (원본 크레파스 화풍)
- 장면마다 2~3장 뽑아서 제일 나은 1장만, 제목 옆 **파일 이름** 그대로 저장
- 다 뽑으면 `Desktop/book/drafts/bg/incoming/` 에 넣고 말해 주세요 (자르기·썸네일·목록 추가는 제가)
- 사람·동물·글씨가 들어간 그림은 빼기
