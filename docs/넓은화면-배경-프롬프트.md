# 넓은 화면(PC) 배경 프롬프트 (복사해서 바로 쓰는 판)

PC처럼 넓은 화면에서 일기장 **뒤에** 깔리는 배경이에요. 나 → 기본 설정 → '넓은 화면(PC) 일기장 뒤 배경'에서 고르게 돼요.
장면마다 회색 칸 하나를 통째로 복사해서 붙여 넣으면 돼요 (20장면).

- 비율 **16:9 가로**, 가능한 크게 (가로 2400px 이상이면 좋아요)
- 참고 그림 `Desktop/book/drafts/bg/_ref-original.png` 를 같이 첨부 (원본 크레파스 화풍)
- 장면마다 2~3장 뽑아서 제일 나은 1장만, 제목 옆 **파일 이름** 그대로 저장 (모두 `pc-` 로 시작해서 그림칸 배경과 안 섞여요)
- 다 뽑으면 한 폴더에 모아서 위치만 알려 주세요 (자르기·썸네일·설정 화면 추가는 제가)
- 빼 주세요: 사람·얼굴·글자·숫자가 들어간 그림, **가운데까지 그림이 꽉 찬 그림** (가운데는 일기장에 가려져요)

## 가운데를 비우는 이유

| 왼쪽 1/3 | 가운데 1/3 | 오른쪽 1/3 |
| :---: | :---: | :---: |
| 볼거리 (위아래로 고르게) | **일기장이 올라가는 자리** → 하늘·종이·책상 같은 바탕만 | 볼거리 (위아래로 고르게) |

맨 가장자리는 화면 비율에 따라 조금 잘려서, 중요한 것은 가장자리에서 조금 안쪽에 두면 좋아요.

```text
첨부한 참고 그림의 화풍을 그대로 따라 그려 줘: 아이가 하얀 도화지에 크레파스로 그린 그림, 크레파스 결과 종이 결이 보이고 선이 살짝 삐뚤삐뚤하고 색이 따뜻한 그림. 참고 그림 속 남자아이, 라면, 반찬, 식탁은 그리지 마. 그릴 장면: 밤. 남색 밤하늘에 크레파스로 그린 별, 초승달, 별똥별. 양옆 아래에 창문 불이 켜진 작은 집과 나무 그림자. 가운데는 별 몇 개뿐인 밤하늘. 밤하늘은 진한 남색이어도 괜찮아. 이 그림은 넓은 PC 화면의 배경이야. 화면 가운데에 세로로 긴 그림일기장(화면 너비의 3분의 1쯤)이 올라가서 가운데는 가려져. 그래서 볼거리는 왼쪽 3분의 1과 오른쪽 3분의 1에 위아래로 고르게 나눠 그리고, 가운데 3분의 1은 바탕만 단순하게 비워 둬. 양쪽 맨 가장자리에는 중요한 것을 두지 마. 위에 올라갈 일기장이 잘 보이게 색은 연하고 차분하게, 대비는 너무 세지 않게. 사람, 얼굴, 글자, 숫자, 간판 글씨, 로고, 워터마크는 넣지 마. 테두리나 액자 없이 16:9 가로 화면을 꽉 채워.
```
