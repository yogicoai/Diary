## 2단계: 공유 링크 + 측정 (돈 안 드는 단계)

- 지금 링크(`/d#…`)는 서버 없이 동작하지만 카톡 미리보기가 사이트 공통 그림이다. 서버 저장으로 바꿔 `/d/[id]`에서 `next/og`로 일기마다 미리보기 그림을 만든다 (원본의 "카톡 미리보기 미검증" 문제를 여기서 해결). 이미 보낸 `#` 링크도 계속 열리게 둔다.
- 링크용 일기는 서버에 저장해야 한다: Mongo(일기 글·획) + 이미지 저장소. **결정 필요: 이미지 저장소** (Vercel Blob / Cafe24 FTP / Supabase Storage).
- 측정: GA4 `window.PD_TRACK` 연결 (원본 Jay 계획 그대로). 이벤트: diary_created, card_save, card_share, price_vote.
- 지인 테스트 통과 기준(원본 유지): 카드 500장, 공유율 20% 이상 / 5% 미만이면 디자인 다시.

## 3단계: AI 그림 (유료 핵심)

- `/api/draw` (서버): 일기 세 줄 → 장면 설명 → 이미지 모델 → 4:3 크레파스 그림 → 그림칸에 넣고, 그 위에 손으로 더 그릴 수 있게.
- 화풍 고정: "어린이가 크레파스로 그린 그림" 레퍼런스 몇 장을 매번 같이 넣는다. 모델은 GPT 이미지와 제미나이를 같은 일기 10개로 비교해서 고른다 (실행 전 장수·비용 확인).
- "나 닮은 어린이": 사진 1장 → 어린이 캐릭터 한 번 만들기 → 이후 그림마다 레퍼런스로.
- 실패하면 크레딧 자동 반환. 첫 사용 때 국외 이전 동의.

## 4단계: 계정·크레딧·결제

- 로그인: 카카오. 크레딧 장부는 원본 설계 유지(잔액 = 거래 내역 합계, order_id 중복 지급 방지).
- 결제 경로가 둘로 갈린다: **웹 = 토스페이먼츠 / 안드로이드 앱 = Google Play 결제**. 앱 안에서 디지털 상품을 외부 PG로 팔면 심사에서 걸린다. 수수료 차이는 수익구조 문서 참고.
- 사업자등록·PG 가맹은 Jay 쪽 일 (원본 4번).
