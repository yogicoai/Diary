- 지금 링크(`/d#…`)는 서버 없이 일기를 주소에 담는다.

  - 일기마다 미리보기를 주려면 서버 저장 `/d/[id]` 와 `next/og` 가 필요하다. 저장소는 지금 쓰는 카페24 를 쓴다.
